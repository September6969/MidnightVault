# MidnightVault Windows 客户端视觉规范

## 设计判断

这是面向私人数据可靠性的 WinUI 3 管理客户端。用户首先需要确认备份是否安全、下一次任务何时执行、手机与硬盘是否就绪。因此视觉方向采用「午夜保管库」：原生 Fluent 结构、克制的冷色强调、清晰的状态层级，以及少量具有品牌辨识度的空状态插画。

- 改版模式：保留业务、导航与文案语气的定向演进
- 设计系统：WinUI 3 与 Fluent
- DESIGN_VARIANCE：3，保持桌面管理工具的稳定与可预测
- MOTION_INTENSITY：2，只保留平台控件自带的状态反馈
- VISUAL_DENSITY：6，在不拥挤的前提下提高状态信息密度

## 视觉 token

- 品牌强调色：冷静的保管库蓝，深色主题使用 `#5BB8E8`，浅色主题使用 `#006E9C`
- 背景与表面：优先使用 Mica 和 WinUI 系统表面资源，不硬编码页面底色
- 状态色：成功、警告、错误继续使用系统语义色，不作为装饰色
- 字体：Segoe UI Variable 与 WinUI 默认字阶
- 页面标题：32px，SemiBold
- 区块标题：20px，SemiBold
- 正文：14px，Regular
- 卡片圆角：8px
- 控件圆角：保留平台默认值
- 页面最大宽度：1120px
- 宽屏页边距：36px
- 中等宽度页边距：24px
- 窄屏页边距：20px
- 阴影：不自定义外发光，依靠 Mica、层级填充和细描边建立深度

## 页面层级

1. 标题区说明当前页面任务，并只保留一个主动作。
2. 就绪状态区集中显示需要用户处理的前置条件。
3. 核心指标使用不对称权重，首要指标面积更大。
4. 列表与空状态提供明确下一步，不只陈述“没有内容”。
5. 中等宽度提前进入重排，避免按钮和时间被裁切。

## 资产策略

导航、按钮、刷新、设备等功能图标继续使用 Segoe Fluent Icons，确保缩放、主题着色和无障碍一致。图像模型仅生成四个具有独特视觉语言的空状态插画：首次备份、空资料库、设备配对、硬盘设置。所有元素来自同一 2x2 图集，并通过可重复脚本切割、去色键、裁边和统一尺寸。
