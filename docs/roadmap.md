## 真实设备上线验收

以下项目需要用户硬件和私有凭据，不能在开发机上伪造为“已通过”：

- [ ] 两台真实 Android 手机在同一午夜并行完成一次任务；
- [ ] 50GB 以上首次备份经历断网、手机重启和 PC 重启后续传；
- [ ] 抽样比对手机与硬盘 SHA-256；
- [ ] 拔出/换错外接硬盘时确认无文件落到系统盘；
- [ ] 配置正式 Cloudflare Tunnel HTTPS 与访问策略；
- [ ] 使用用户自己的 Android keystore 和 Windows PFX 产出最终签名包。

这些验收未完成前，版本定位为私人 Beta，不建议把 Receiver 端口直接暴露到公网。
